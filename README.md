الرابط: https://shawa-blood.github.io/

## التسجيل والتحديث
- زر «التسجيل» في الدليل يفتح نموذج Google: «نموذج تسجيل متطوع تحت الطلب للتبرع بالدم بشاوة».
- الردود تُحفظ في شيت «نموذج تسجيل متطوع تحت الطلب للتبرع بالدم بشاوة (الردود)».
- `tools/sync.py` يضيف الردود الجديدة فقط إلى `index.html` (بدون تواريخ ميلاد، وبدون أرقام من هم دون 18 سنة) ويحفظ آخر صف تمت معالجته في `tools/sync-state.json`.
